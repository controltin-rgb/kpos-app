# การติดตั้ง KPOSS (สำหรับผู้ติดตั้งระบบที่ร้าน)

เป้าหมาย: ติดตั้งบนเครื่องเปล่าจนขายได้ภายในไม่เกิน 1 ชั่วโมง (Implement.md เฟส 4 / Design-Spec เฟส 5)

## ไฟล์ตัวติดตั้ง
| ระบบ | ไฟล์ | หมายเหตุ |
| --- | --- | --- |
| Windows 10/11 (64-bit) | `KPOSS-<เวอร์ชัน>-win-x64.exe` | ติดตั้งทั้งเครื่องใน Program Files ต้องกด "Yes" ที่หน้าต่างสิทธิ์ผู้ดูแล (UAC) |
| macOS (Intel / Apple Silicon) | `KPOSS-<เวอร์ชัน>-mac-x64.dmg` / `-mac-arm64.dmg` | ยังไม่ได้ลงลายเซ็น: ครั้งแรกให้คลิกขวาที่แอป → Open |
| Linux | `KPOSS-<เวอร์ชัน>-linux-x86_64.AppImage` | `chmod +x` แล้วเปิดได้เลย (อัปเดตอัตโนมัติได้) |
| Linux (สำรอง) | `KPOSS-<เวอร์ชัน>-linux-x64.tar.gz` | แตกไฟล์แล้วรัน `kposs` (สำหรับเครื่องที่เปิด AppImage ไม่ได้) |

ตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล (code signing) Windows อาจขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**

ไฟล์สร้างโดย GitHub Actions (`.github/workflows/build.yml`) เมื่อติดแท็ก `v*` หรือกด Run workflow เอง หรือสร้างเองบนเครื่องของระบบนั้น ๆ ด้วย `pnpm build:win` / `pnpm build:mac` / `pnpm build:linux` (ผลลัพธ์อยู่ใน `release/`)

## ขั้นตอนบนเครื่องหลัก (Host) หรือเครื่องเดี่ยว
1. รันตัวติดตั้ง → เลือกโฟลเดอร์ (ค่าเริ่มต้นได้) → ติดตั้ง
   - ตัวติดตั้งเพิ่มกฎ Windows Firewall ชื่อ **KPOSS (LAN)** ให้เครื่องในวง LAN เดียวกันต่อเข้ามาได้ (เฉพาะ local subnet) จึงไม่มีหน้าต่าง Firewall ถามตอนเปิดใช้
2. เปิดแอป → หน้าตั้งค่าครั้งแรก: ชื่อร้าน สาขา และบัญชีผู้ดูแลสูงสุด
3. **License**: ตั้งค่า → เครื่องและ License คัดลอก Hardware ID ส่งให้ผู้ขาย แล้วนำเข้าไฟล์ `.LIC` ที่ได้รับ (ระหว่างนี้ใช้รุ่นทดลอง 30 วันได้)
4. ตั้งค่าร้าน: VAT, ข้อมูลผู้ขายสำหรับใบกำกับภาษี, PromptPay, เครื่องพิมพ์ใบเสร็จ
5. **Backup**: หน้า Backup / Restore → เปิด "ไดรฟ์ภายนอก / NAS" แล้วเลือกโฟลเดอร์บน USB, NAS หรือโฟลเดอร์ที่ซิงก์ขึ้นคลาวด์ (ต้องไม่ใช่ดิสก์เดียวกับเครื่อง) — สแนปช็อตรายวันและบันทึกการเปลี่ยนแปลงทุก 10 วินาทีจะถูกคัดลอกไปที่นั่น
6. ถ้ามีหลายเครื่อง: ตั้งค่า → เครื่องและ License → เลือก **เครื่องหลัก (Host)** แล้วกด **"เพิ่มเครื่องลูก"** เพื่อสร้างรหัสจับคู่

## ขั้นตอนบนเครื่องลูก (Client: POS-02, KDS)
1. ติดตั้งเหมือนเครื่องหลัก (เครื่องอยู่ในวง LAN/Wi-Fi เดียวกับเครื่องหลัก)
2. เปิดแอป → หน้าตั้งค่าครั้งแรก เลือก **"เชื่อมต่อกับเครื่องหลัก"** → ใส่ที่อยู่เครื่องหลัก (เช่น `192.168.1.10:3000`) และรหัสจับคู่ 8 ตัวที่แสดงบนเครื่องหลัก
3. แอปรีสตาร์ทเป็นเครื่องลูก → ล็อกอินด้วยบัญชีพนักงาน ระหว่างที่เครื่องหลักยังออนไลน์ (ครั้งแรกต้องออนไลน์ จึงจะขายออฟไลน์ได้ภายหลัง)

## อัปเดตเป็นเวอร์ชันใหม่ (D39, D42)
- อัปเดต **เครื่องหลักก่อน** แล้วค่อยเครื่องลูก
- ครั้งแรกที่เปิดเวอร์ชันใหม่ ระบบสำรองฐานข้อมูลเดิมให้อัตโนมัติ (ชนิด "ก่อนอัปเดตแอป" ในหน้า Backup) ก่อนปรับโครงสร้างข้อมูล

**อัปเดตอัตโนมัติ** (Windows ตัวติดตั้ง .exe และ Linux AppImage)
1. ผู้ขาย: build เวอร์ชันใหม่ (เพิ่มเลข `version` ใน package.json) แล้วอัปโหลดไฟล์จาก `release/` ขึ้นโฟลเดอร์ HTTPS ของตัวเอง เช่น `https://updates.example.com/kposs/`
   - Windows: `KPOSS-<เวอร์ชัน>-win-x64.exe`, `.exe.blockmap`, `latest.yml`
   - Linux: `KPOSS-<เวอร์ชัน>-linux-x86_64.AppImage`, `latest-linux.yml`
   - macOS: `.zip`, `latest-mac.yml` (แอปจะแจ้งว่ามีเวอร์ชันใหม่ แต่ยังติดตั้งเองไม่ได้จนกว่าจะลงลายเซ็น)
   - อัปโหลดไฟล์ติดตั้งก่อน แล้วค่อยอัปโหลด `latest*.yml` เป็นไฟล์สุดท้าย
   - **ทางลัด (GitHub Releases):** push tag เวอร์ชัน เช่น `git tag -a v0.3.0 -m "KPOSS 0.3.0" && git push origin v0.3.0` แล้ว CI จะ build ทั้ง 3 ระบบและสร้าง Release พร้อมไฟล์ข้างบนให้เอง (tag ที่มี `-` เช่น `v0.3.0-rc.1` เป็น pre-release และร้านจะไม่ได้รับ) URL ที่ร้านใส่คือ `https://github.com/controltin-rgb/kpos-app/releases/latest/download`
   - Google Drive ใช้เป็น URL อัปเดตไม่ได้ (ลิงก์อ้างไฟล์ด้วยรหัส ต่อชื่อไฟล์ไม่ได้ และไฟล์ใหญ่ติดหน้ายืนยันสแกนไวรัส) ใช้ได้เฉพาะแจกตัวติดตั้งให้ร้านอัปเดตด้วยมือ
2. ร้าน: ตั้งค่า → เครื่องและ License → **อัปเดตอัตโนมัติ** ใส่ URL โฟลเดอร์นั้น (ใส่ที่เครื่องหลักครั้งเดียว เครื่องลูกใช้ URL เดียวกัน)
3. แอปตรวจตอนเปิดและทุก 6 ชั่วโมง ดาวน์โหลดไว้ก่อน แล้วแจ้งที่ ระบบ → เกี่ยวกับระบบ → **ติดตั้งและรีสตาร์ท** (ไม่ติดตั้งเองระหว่างขาย)

**อัปเดตด้วยมือ** (macOS, tar.gz หรือไม่ได้ตั้ง URL): ปิดแอปทุกเครื่อง แล้วรันตัวติดตั้งเวอร์ชันใหม่ทับได้เลย ข้อมูลร้านไม่หาย (อยู่ที่ `%APPDATA%\KPOSS` ไม่ได้อยู่ในโฟลเดอร์โปรแกรม)

## สำรองขึ้นคลาวด์ (D43)
1. สร้าง bucket ที่ผู้ให้บริการแบบ S3 (แนะนำ Cloudflare R2 — ไม่มีค่าดาวน์โหลด) และ Access key ที่เขียน/อ่าน/ลบได้เฉพาะ bucket นั้น
2. License ของร้านต้องเปิด "สำรองขึ้นคลาวด์" (`--cloud` / สวิตช์ในเครื่องมือออก License)
3. หน้า Backup / Restore → การ์ด **สำรองขึ้นคลาวด์** ใส่ Endpoint, Bucket, Access key, Secret key และ **รหัสผ่านเข้ารหัส** → บันทึก → ทดสอบการเชื่อมต่อ → เปิดสวิตช์
4. **จดรหัสผ่านเข้ารหัสเก็บไว้นอกเครื่อง** ถ้าลืม ไฟล์บนคลาวด์จะเปิดไม่ได้
5. เครื่องเสีย/ย้ายเครื่อง: ติดตั้งใหม่ → ตั้งร้านชั่วคราว → ใส่ค่าคลาวด์เดิม → **ดาวน์โหลดจากคลาวด์** → เลือกชุดสำรองแล้วกู้คืนตามปกติ

## ออก License (ฝั่งผู้ขาย)
- `pnpm license:tool` เปิดหน้าออก License ในเบราว์เซอร์ (เฉพาะเครื่องนี้) — ออกไฟล์ / ดูทะเบียน / ต่ออายุ / ตรวจไฟล์ .LIC
- คีย์ลับอยู่ที่ `~/.kposs/license-signing-key.pem` และทะเบียนที่ `~/.kposs/issued-licenses.jsonl` — **สำรองทั้งสองไฟล์ไว้นอกเครื่อง** ห้ามใส่ในรีโป

## ถอนการติดตั้ง
- Windows: Settings → Apps → KPOSS → Uninstall (ลบกฎ Firewall ให้ด้วย)
- ข้อมูลร้านและไฟล์สำรองใน `%APPDATA%\KPOSS` **ไม่ถูกลบ** ถ้าต้องการลบจริงให้ลบโฟลเดอร์นั้นเอง (สำรองไว้ก่อน)

## ตรวจตัวติดตั้งก่อนส่งร้าน
```
pnpm smoke release/win-unpacked/KPOSS.exe --relaunch
```
เปิดแอปที่แพ็กแล้วบนโฟลเดอร์ข้อมูลว่าง ตรวจว่าหน้าจอขึ้น ฐานข้อมูล migrate ครบ ระบบบันทึกการเปลี่ยนแปลงทำงาน และการรีสตาร์ทตัวเอง (เช่นหลังกู้คืน) ไม่ชนกับตัวเดิม แล้วปิดตัวเอง

## เช็กลิสต์ทดสอบบนเครื่องจริงก่อนใช้ที่ร้าน
ทำครั้งแรกก่อนส่งมอบ และทุกครั้งที่ออกเวอร์ชันใหม่ ใช้เครื่อง Windows อย่างน้อย 2 เครื่องในวง LAN/Wi-Fi เดียวกัน

**ตัวติดตั้ง (เครื่อง A)**
- [ ] รัน `KPOSS-<เวอร์ชัน>-win-x64.exe` → ขึ้นหน้าต่างขอสิทธิ์ (UAC) → ติดตั้งสำเร็จ มีไอคอนบน Desktop และ Start Menu
- [ ] เปิด PowerShell: `netsh advfirewall firewall show rule name="KPOSS (LAN)"` → พบกฎ 1 รายการ (Enabled: Yes, RemoteIP: LocalSubnet)
- [ ] เปิดแอป → หน้าตั้งค่าครั้งแรก → ตั้งร้าน → ขายได้ 1 บิล
- [ ] ดับเบิลคลิกไอคอนซ้ำ → ไม่มีหน้าต่างที่สอง (หน้าต่างเดิมเด้งขึ้นมาแทน)

**Host / Client ข้ามเครื่อง**
- [ ] เครื่อง A: ตั้งค่า → เครื่องและ License → เครื่องหลัก (Host) → เพิ่มเครื่องลูก (จดที่อยู่ IP:3000 และรหัส 8 ตัว)
- [ ] เครื่อง B: ติดตั้ง → "เชื่อมต่อกับเครื่องหลัก" → จับคู่สำเร็จโดย **ไม่มีหน้าต่าง Firewall ถาม** ที่เครื่อง A
- [ ] เครื่อง B: ล็อกอิน → เปิดกะ → ขาย → บิลขึ้นที่เครื่อง A (บิลและประวัติ) และจอบาร์
- [ ] ปิดแอปเครื่อง A → เครื่อง B ชิปเปลี่ยนเป็น "ขายออฟไลน์" → ขายต่อได้ 2–3 บิล
- [ ] เปิดเครื่อง A กลับมา → ภายใน 1 นาทีบิลออฟไลน์ขึ้นที่เครื่อง A ครบ ไม่ซ้ำ เลขบิลไม่ชน
- [ ] ดึงสาย LAN / ปิด Wi-Fi ของเครื่อง B ระหว่างขาย แล้วต่อกลับ → ผลเหมือนข้อบน

**Backup / อัปเดต**
- [ ] หน้า Backup: เลือกโฟลเดอร์ USB → "สำรองข้อมูลตอนนี้" → มีไฟล์ใน USB และโฟลเดอร์ `journal`
- [ ] กู้ย้อนเวลา (ระดับ B) เป็นไฟล์ตรวจสอบ → ตัวเลขบิลตรงกับที่คาด
- [ ] ติดตั้งเวอร์ชันใหม่ทับ (หรือเวอร์ชันเดิมซ้ำโดยแก้เลขเวอร์ชันตอน build) → ข้อมูลอยู่ครบ หน้า Backup มีชุด "ก่อนอัปเดตแอป"
- [ ] ถอนการติดตั้ง → กฎ Firewall หายไป แต่ `%APPDATA%\KPOSS` ยังอยู่
- [ ] อัปเดตอัตโนมัติ: วางไฟล์เวอร์ชันใหม่บนเซิร์ฟเวอร์ → ระบบ → เกี่ยวกับระบบ → ตรวจหาอัปเดต → ติดตั้งและรีสตาร์ท → เวอร์ชันเปลี่ยน ข้อมูลอยู่ครบ
- [ ] คลาวด์: ส่งขึ้นคลาวด์ตอนนี้ → มีไฟล์ `.enc` ใน bucket → เครื่องอื่นดาวน์โหลดจากคลาวด์แล้วกู้คืนได้

**ไฟดับ / ปิดเครื่องกะทันหัน**
- [ ] ระหว่างกดชำระเงิน ถอดปลั๊กเครื่อง (หรือปิดด้วย Task Manager) → เปิดใหม่ → บิลล่าสุดมีครบหรือไม่มีเลย ไม่มีบิลค้างครึ่ง ๆ สต็อกและลิ้นชักตรงกับบิล
- [ ] หน้า Audit Log → ตรวจสอบความสมบูรณ์ → ผ่าน
